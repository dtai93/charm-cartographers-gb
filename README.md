Biscuit Isle is a treasure chart of a shortbread island with a bite taken out of the north-east. The Steeping River runs from Mount Kettle into Dunking Lagoon, and the walk ends at the last biscuit. `build/render.py` draws it with Pillow and numpy: a fixed-seed parchment wash, a smooth teal sea, ink coast and ripples, then the places, the teapot kraken, and the teaspoon compass.

## Run it

```sh
python3 build/render.py   # redraws entry.png
node main.ts             # copies it to /output/entry.png
```
